== 1. LOAD DATA LOCAL INPATH copies a file into the table folder
> CREATE TABLE zones (id INT, borough STRING, zone STRING)
     ROW FORMAT DELIMITED FIELDS TERMINATED BY ',' STORED AS TEXTFILE
> LOAD DATA LOCAL INPATH '~/spark-masterclass-parts/sql-ddl/data/work/ch85-load/inbox/zones_1.csv' INTO TABLE zones
  inbox:
    zones_1.csv  (42 B)
    zones_2.csv  (58 B)
    zones_3.csv  (30 B)
  table folder:
    zones_1.csv  (42 B)
> SELECT * FROM zones ORDER BY id
+---+-------+--------------+
|id |borough|zone          |
+---+-------+--------------+
|1  |EWR    |Newark Airport|
|2  |Queens |Jamaica Bay   |
+---+-------+--------------+

== 3. OVERWRITE replaces the files of the table
> LOAD DATA LOCAL INPATH '~/spark-masterclass-parts/sql-ddl/data/work/ch85-load/inbox/zones_3.csv' OVERWRITE INTO TABLE zones
  table folder:
    zones_3.csv  (30 B)
> SELECT * FROM zones
+---+-------------+-------------+
|id |borough      |zone         |

|5  |Staten Island|Arden Heights|
